بحث عن لغة CSS

دور أوراق الأنماط المتتالية في تنسيق صفحات الويب

١. مقدمة عن لغة CSS

لغة CSS هي اختصار لعبارة Cascading Style Sheets، وتعني أوراق الأنماط المتتالية. تُستخدم هذه اللغة لتنسيق صفحات الويب والتحكم في شكل العناصر المكتوبة بلغة HTML، مثل الألوان والخطوط والأحجام والمسافات والخلفيات والحدود. تساعد CSS على تحويل صفحة بسيطة إلى صفحة منظمة وجذابة وسهلة القراءة.

٢. صورة توضيحية عن CSS

توضح الصورة مثالًا على كود CSS وكيفية تأثيره في شكل العناصر داخل صفحة الويب. يجب وضع الصورة في المجلد نفسه الذي يوجد به ملف HTML حتى تظهر بصورة صحيحة.

٣. أهمية استخدام CSS

  • تحسين المظهر: تساعد على اختيار الألوان والخطوط والتنسيقات المناسبة.
  • تنظيم الصفحات: تجعل المحتوى أكثر وضوحًا وسهولة في القراءة.
  • توفير الوقت: يمكن استخدام ملف تنسيق واحد لتوحيد شكل صفحات متعددة.
  • التوافق مع الأجهزة: تساعد في تصميم صفحات تناسب الهواتف والأجهزة اللوحية والحواسيب.
  • سهولة التعديل: يمكن تغيير التصميم بتعديل قواعد CSS بدلًا من تعديل كل عنصر على حدة.

٤. طريقة كتابة كود CSS

تتكون قاعدة CSS عادةً من مُحدِّد يحدد العنصر المطلوب تنسيقه، ثم مجموعة من الخصائص والقيم. يوضح المثال التالي طريقة تغيير لون العنوان ومحاذاته وحجم الخط:

h1 {
  color: purple;
  text-align: center;
  font-size: 28px;
}

في هذا المثال، يصبح لون العنوان بنفسجيًا، ويظهر في منتصف الصفحة، ويكون حجم الخط ٢٨ بكسل.

٥. أشهر خصائص CSS

الخاصيةوظيفتهامثال
colorتغيير لون النصcolor: blue;
background-colorتحديد لون الخلفيةbackground-color: white;
font-sizeتحديد حجم الخطfont-size: 20px;
marginتحديد المسافة خارج العنصرmargin: 10px;
paddingتحديد المسافة داخل العنصرpadding: 12px;
borderإضافة إطار حول العنصرborder: 1px solid gray;

٦. أنواع CSS

التنسيق الداخلي المباشر: يُكتب داخل وسم HTML باستخدام الخاصية style.

التنسيق الداخلي للصفحة: يُكتب داخل وسم style في جزء الرأس من ملف HTML.

التنسيق الخارجي: يُكتب في ملف مستقل امتداده .css، ثم يتم ربطه بصفحة HTML. ويُعد هذا النوع مناسبًا عند تنسيق عدة صفحات بالمظهر نفسه.

٧. الخاتمة

تُعد CSS من التقنيات الأساسية في تصميم وتطوير مواقع الويب، إذ تعمل مع HTML لتحديد شكل الصفحة وطريقة عرض محتواها. ويساعد تعلم خصائصها ومحدداتها على إنشاء مواقع أكثر تنظيمًا وجمالًا وتوافقًا مع مختلف أحجام الشاشات.
